# Büroarbeit im ambulanten Betreuungsdienst digitalisieren: 7-Punkte-Selbstcheck (ohne KI-Hype)

**Kostenlose, unabhängige Arbeitshilfe.** Viele kleine Teams haben einen Mix aus Telefonnotizen, E-Mail, Papier und Tabellen. Das bedeutet nicht automatisch, dass ein KI-Agent die richtige Lösung ist. Oft reicht zuerst ein klarer Eingangskanal, eine Zuständigkeitsregel oder eine Erinnerung in bereits genutzter Software.

> **Transparenz:** Dieses Beispiel ist vollständig fiktiv. Es bezieht sich auf keinen tatsächlichen Kundenauftrag. Es enthält keine personenbezogenen Gesundheits- oder Pflegedaten und beansprucht weder zertifizierte Datenschutzprüfung noch belegte Einsparungen.

## Ein konkretes Beispiel: Eine Anfrage kommt telefonisch herein

Ein fiktives Betreuungsteam erhält Anfragen über Telefon und E-Mail. Mitarbeitende notieren Termine auf Zetteln und übertragen später Informationen in eine Liste. Manche Anfragen bleiben liegen, während andere mehrfach erfasst werden.

Das Ziel eines ersten, begrenzten Tests lautet nicht „alles automatisieren“, sondern:

1. Jede **administrative** Anfrage bekommt eine eindeutige interne Vorgangsnummer.
2. Es gibt eine verantwortliche Person für die Triage.
3. Dringende und fachlich kritische Vorgänge folgen ausschließlich einer **menschlich verantworteten** internen Regel.
4. Für Rückmeldungen werden Fristen und Status nachvollziehbar festgehalten.
5. Klienten-/Patientendaten bleiben in den rechtlich und organisatorisch freigegebenen Systemen.

## Kopierbare Checkliste für einen einzigen Büroprozess

| Prüfpunkt | Frage | Antwort im Team |
|---|---|---|
| Eingang | Über welche Kanäle kommt die Anfrage? | Telefon / E-Mail / Post / Sonstiges |
| Zweck | Welcher konkrete administrative Schritt soll verbessert werden? | Freitext |
| Zuständigkeit | Wer übernimmt den Vorgang? | Rolle statt Klientenname |
| Daten | Sind Gesundheits- oder andere sensible Daten betroffen? | Ja / Nein / Ungeklärt |
| Doppelarbeit | Welche Informationen werden unnötig zweimal eingegeben? | Beispiele ohne Kundendaten |
| Ausnahme | Wann muss eine Person ausdrücklich entscheiden? | Freitext |
| Erfolg | Welche Zahl lässt sich vor und nach dem Pilot erfassen? | Anzahl offene Vorgänge / Dubletten / Zeitaufwand |

## Mensch, einfache Software oder KI?

**Menschliche Bearbeitung:** Wenn ein Vorgang fachliches Urteil, Versorgung, Einwilligung, Datenschutzentscheidung oder sensible Ausnahmen betrifft.

**Vorhandene Software / einfache Automatisierung:** Wenn feste Regeln, Formulare, Erinnerungen oder Statuswechsel ausreichen. Prüfen, ob die bereits eingesetzten Programme diese Funktionen anbieten.

**KI höchstens als begrenzter, freigegebener Pilot:** Wenn tatsächlich unstrukturierte Textinformationen verarbeitet werden müssen und Rechtsgrundlage, Datenzugriff, Freigaben, Protokollierung, Fehlerrisiken und menschliche Kontrolle geklärt sind. Keine Klienten-/Patientendaten in private KI-Chatbots kopieren.

## Vier Kennzahlen statt erfundener „Zeitersparnis“

- **Unzugeordnete Vorgänge:** Wie viele Aufgaben haben nach einem intern festgelegten Zeitraum keinen klaren Bearbeiter?
- **Doppelte Eingaben:** Wie viele Schritte übertragen dieselbe Information erneut?
- **Ausnahmen:** Wie oft fällt ein Vorgang aus dem Standardablauf heraus und benötigt bewusste Fachprüfung?
- **Rückfragen:** Wie viele Nachfragen entstehen, weil eine wichtige Angabe fehlt?

Zuerst die Ausgangswerte in einer verantworteten, zulässigen Umgebung erheben. Dann einen kleinen Pilot planen. Ohne Vergleichsdaten sind pauschale Prozentversprechen wertlos.

## Wann wir stoppen

Wenn die Verantwortlichen, die Rechtsgrundlage, die Datenspeicherung oder ein geeigneter menschlicher Prüfpunkt unklar sind, darf die angedachte Automatisierung nicht einfach produktiv geschaltet werden. Für ambulante Pflege- und Betreuungsdienste können zusätzliche fachrechtliche Vorgaben gelten.
