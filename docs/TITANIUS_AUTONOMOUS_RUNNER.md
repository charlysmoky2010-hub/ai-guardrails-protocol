# TITANIUS autonomous public runner

This is the no-ChatGPT-credit, no-commercial-AI-key execution companion
for the private TITANIUS_CERBERRUS finance brain.

## Actual independent tasks

- **Every six hours:** inspect the real MicroVault digital report checkout
  and its public distribution URL, plus the AI App Rescue URL. Record live HTTP
  outcomes, publicly observable title/metadata/SEO clues, and missing offer
  claims. Invalid redirects are never used to bypass host restrictions.
- **Persistent memory:** open/update just one GitHub Issue
  ([live work queue](https://github.com/charlysmoky2010-hub/ai-guardrails-protocol/issues/1))
  with open tasks and repeated-cycle evidence.
- **Weekly:** open-source Lighthouse mobile audits with actual
  performance, accessibility, best-practices and SEO categories.
- **On every edit:** standard-library unit tests and external-audit
  evidence checks; no synthetic sales.

The trusted private finance ledger and customer identities remain outside this
public repository. These workers CANNOT authoritatively verify Stripe revenue,
real customer delivery, net profit, or settlement. Any such data stays
UNKNOWN until an authenticated read-only provider source exists.

## Scheduled processes

- `.github/workflows/titanius-control-center.yml`: `17 */6 * * *` UTC
- `.github/workflows/titanius-design-agent.yml`: Monday 07:29 UTC

Schedules must remain on the default branch; public repos may automatically
lose scheduled workflows after 60 days without activity. The initial push
triggered actual successful independent checks, but future cron execution
must continue to be verified through the Actions run history.

## Original reusable Claude design skill

`.claude/skills/titanius-design-director/SKILL.md` can be used by a coding
assistant with repo access. It does not grant a model, money, or background
execution by itself. Its review stages are evidence -> design system ->
bounded implementation -> independent retest. See the upstream Vercel Web
Interface Guidelines and GoogleChrome Lighthouse CI.

## Invariants

The worker's GitHub token permits updating its own audit issue.
It never changes product prices, Stripe destinations, wallets, user records,
deployment or public content. Autonomous source changes require a separately
reviewed proposal. A 100/100 structural or Lighthouse score is NOT a
10/10 aesthetic design, guarantee of revenue, or customer success story.
